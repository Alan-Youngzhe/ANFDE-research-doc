## 证据原则

- **职位事实与企业级方法论分开**；正式定义与跨材料综合推断分开
- 不自动把转型顾问、解决方案架构师或普通实施工程师称为 FDE
- 对常见夸大（如"Block 已有公司世界模型产品"、"谈判学是伪科学"）逐条核查并给出更准确的表述
